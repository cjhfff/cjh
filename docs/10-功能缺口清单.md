# 10 功能缺口清单（2026-11-18 晚，对照 01-功能清单）

方法：逐条对照 `01-功能清单.md` 的 MVP / P1，检查 `src/server/app.ts` 的路由、数据库表、`src/renderer` 的界面和 `src/cli`。界面在浏览器里接到守护进程上逐页看过。

现状：后端链路稳定（端到端测试全过），界面有 4 页（对话、模型与 ACP、MCP 与技能、用量与系统），但**功能面只覆盖了 MVP 的骨架，P1 基本没做**。

## A. MVP 里缺的或只做了一半的

| # | 功能 | 现状 | 要做的 |
|---|---|---|---|
| A1 | 线程重命名 | 后端 `PUT /api/threads/:id` 支持，界面没有入口 | 侧边栏右键 / 双击标题重命名；手动改名后 `titleSource=manual` |
| A2 | 线程删除、批量删除、归档 | 后端有删除和批量删除，没有归档接口；界面都没有入口 | 侧边栏右键菜单：删除、归档、置顶；多选批量删除；「已归档」分组可恢复 |
| A3 | 编辑用户消息后重发 | 引擎支持 `replaceMessageId`，界面没有 | 用户消息悬停出现「编辑」，改完重发，生成新分支，用户消息也显示 `< m / n >` |
| A4 | ACP 斜杠命令 | 后端收到 `available_commands_update` 并有 `/api/threads/:id/acp-commands`，界面没用 | 输入框输入 `/` 弹出命令补全（ACP 线程用 agent 的命令，普通线程用 cjh 内置命令如 `/new`、`/model`、`/compact`） |
| A5 | ACP 附件 | ACP 只发文本，图片和文件只变成 `[附加文件: xxx]` | 按 ACP `promptCapabilities` 发 `image` / `resource` / `resource_link` content block；文本文件内联，其他文件发本地路径 |
| A6 | 自动标题兜底 | 没有可用工具模型时标题一直是「新对话」（截图里十几个「新对话」） | 工具模型不可用时，用第一条用户消息截断前 20 字作为标题 |
| A7 | 数据导入 | 只有导出 | `POST /api/data/import`（合并或覆盖可选），界面在「用量与系统」 |
| A8 | 自动更新的安装一步 | 有 check / download，`/api/update/install` 没有；IPC 有 apply | 补完整「检查 → 下载 → 校验 sha256 → 重启替换」流程并在界面串起来 |
| A9 | i18n | 有 84 个 key，但 tsx 里还有约 125 行硬编码中文 | 全部换成 `t('...')` |
| A10 | 全局快捷键、开机自启 | 没有 | 设置里两个开关；默认快捷键 `Alt+Space` 唤出主窗口 |

## B. P1 里价值最高、建议这一轮就做的

| # | 功能 | 为什么重要 | 要做的 |
|---|---|---|---|
| B1 | **ACP 会话恢复** | 现在重启 cjh 或会话空闲 30 分钟被释放后，再在原线程里说话，Claude 完全不记得之前的内容 | agent 支持 `loadSession` 时用 `session/load` 恢复 `threads.metadata.acpSessionId`；不支持时，新会话第一轮把该线程历史压成一段上下文前置 |
| B2 | **定时任务（cron）** | 老大每天 7:30 的 sub2api 日报 | 表 `cron_jobs`、`cron_runs`；cron 表达式 + 时区 + 目标线程 + 提示词 + 模型；到点往线程发 `generate_response`（`source=cron`）；界面新增「定时任务」页：增删改、启停、立即执行、执行历史 |
| B3 | **全文搜索** | 线程多了只能按标题筛 | SQLite FTS5 建 `messages_fts`，`GET /api/search?q=`，侧边栏搜索框同时搜标题和内容，结果点进去定位到消息 |
| B4 | **上下文压缩 + 用量显示** | 长对话会爆上下文 | 头部已显示 `30k / 1000k`；补 `POST /api/threads/:id/compact`（用工具模型把旧消息摘要成一条 system 消息），超过 80% 时提示 |
| B5 | **提示词库** | 常用指令一键插入 | 表 `prompts`；输入框 `/` 菜单里列出；设置页可管理 |
| B6 | **分支对话** | 从某条消息另开一个线程试别的思路 | 消息菜单「从这里分支」，`POST /api/threads/:id/branch`，新线程带 `parent_thread_id` |
| B7 | **线程级工作区面板（只读）** | ACP 改了哪些文件看不见 | 对话右侧可展开面板：工作目录文件树 + `git status` / `git diff`（只读） |
| B8 | **ACP 模式切换** | 现在只能在 provider 上设默认 | 对话头部显示当前模式并可切换（调用 `session/set_mode`），bypass 时标红 |
| B9 | **执行跟踪** | 排查问题用 | 表 `traces`：每轮的模型、耗时、token、工具调用次数、错误；消息菜单「查看跟踪」 |
