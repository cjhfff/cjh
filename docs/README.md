# cjh 参考资料：Alma 拆解

这份资料是给 cjh 做产品和架构设计用的输入。素材来自本机安装的 Alma 0.4.708（Windows 版）：

- 服务端打包文件的结构分析：路由、数据表、环境变量、事件类型
- 本机数据库的表结构和设置项键名（只读了键名，没读具体值）
- 运行日志里的行为记录
- 2026-11-17 实际接入 ACP agent 时踩过的坑

## 边界

- Alma 是闭源商业软件。这里只记录**它有什么功能、数据怎么组织、模块之间怎么协作**，所有描述都是重新写的，不包含它的源代码。
- cjh 的实现必须自己写。功能可以参考，代码、文案、图标、品牌都不能拿。
- 表名、字段名、路由路径是作为“它是怎么分层的”这类事实来记录的。cjh 自己的命名可以重新设计，不用照抄。
