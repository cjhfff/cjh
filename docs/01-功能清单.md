# 01 功能清单

按模块列出 Alma 的全部能力，每项后面给一个 cjh 的建议档位：

- **MVP**：第一版必须有
- **P1**：第二版做
- **P2**：以后有需要再做
- **不做**：和你的场景无关，或者投入产出比太低

括号里是 Alma 对应的路由组或表名，方便到 `raw/` 里查。

---

## 1. 对话（核心）

| 功能 | 说明 | 档位 |
|---|---|---|
| 多线程对话 | 侧边栏列出线程，可以新建、重命名、删除、批量删除、归档（`/api/threads`，表 `chat_threads`） | **MVP** |
| 流式输出 | 逐字输出，内容包括文本、思考过程、工具调用、工具结果 | **MVP** |
| 每个线程单独选模型 | 线程上记录 model、reasoning_effort、fast_mode | **MVP** |
| 消息树 / 多版本 | 消息带 parent_id，重新生成后可以在不同版本之间切换（`switch-version`），也能回滚（`rollback`） | **MVP**（至少要支持重新生成） |
| 生成中途插话（steer） | 模型还在生成时，用户追加的话会并入当前这一轮，而不是排到下一轮 | P1 |
| 停止生成 | WS `stop_generation` | **MVP** |
| 附件 | 图片、文件上传，转成消息的 parts（`/api/attachments`） | **MVP** |
| 上下文压缩 | 手动或自动压缩历史（`/compact`，事件 `context_compacted`），实时显示上下文用量（`context-usage`） | P1 |
| 自动生成标题 | 由一个单独的“工具模型”生成（`regenerate-title`，事件 `title_generated`） | **MVP** |
| 分支对话 | 从某条消息开一个新线程（`/branch`，字段 `parent_thread_id`） | P1 |
| 线程收藏 / 置顶 / 标签 | `is_favorited`、`sidebar_pin_slot`、`thread_labels` | P1 |
| 无痕对话 | `is_incognito`，不落库、不写记忆 | P2 |
| 全文搜索 | SQLite FTS5 建的 `messages_fts`（`/api/search/threads`） | P1 |
| 线程目标 / 循环 | 线程可以挂一个 goal，或者让它按 loop 反复执行（`/goal`、`/loop`） | P2 |
| 快速对话窗口 | 全局快捷键弹出的小窗（路由 `/quick-chat`） | P1 |
| 消息 reaction | 给消息打 emoji | 不做 |

## 2. 模型 Provider

| 功能 | 说明 | 档位 |
|---|---|---|
| Provider 增删改查 | 共 18 种类型，详见 05 | **MVP**（OpenAI 兼容、Anthropic、ACP 三种就够） |
| 拉取模型列表 | `models/fetch`，结果缓存到 `provider_models_cache` | **MVP** |
| 手动编辑模型和能力 | 能力项：视觉、推理、上下文长度、最大输出、流式、函数调用 | **MVP** |
| 模型能力自动探测 | 从 models.dev 拉能力表，缓存 1.4 万条（`model_capabilities_cache`），拉不到就按模型名猜 | P1 |
| 测试连接 | `/test` | **MVP** |
| 自定义请求头、API 版本、Responses API 开关、max_completion_tokens 开关 | 兼容各种中转站的怪癖 | **MVP**（你自己就有 sub2api，一定会用到） |
| 订阅登录 | Claude 订阅、Copilot 等走 OAuth 的账号（`claude-subscription`、`copilot`、`/authenticate`） | P2 |
| 配额刷新 | `refresh-quotas` | P2 |
| 工具模型 | 一个便宜的模型专门做标题、摘要、记忆整理这类杂活（`/api/tool-model`，设置 `toolModel.model`） | **MVP** |

## 3. ACP agent

| 功能 | 说明 | 档位 |
|---|---|---|
| 把 ACP agent 当成一种 provider | Claude Code、Codex、Gemini CLI 等，通过 stdio JSON-RPC 接入 | **MVP** |
| 拉取 agent 的模型、模式、命令 | 解析 `configOptions` 或旧版 `models` 字段；斜杠命令通过 `acp-commands` 获取 | **MVP** |
| 权限请求弹窗 | agent 要执行工具时请求批准（路由 `/permission-overlay`） | **MVP** |
| 把 cjh 自己的工具和 MCP 透传给 agent | provider 上配 `acp_mcp_server_ids`，再加一层 tool proxy | P1 |
| ACP 借用其他 provider 的 API Key | `acp_api_provider_id`：让 Claude Code 使用某个 Anthropic 中转的 key 和 base URL | P1（可以让 agent 走你的 sub2api） |
| 模型名映射 | `acp_model_mapping` | P1 |
| 会话恢复 | `loadSession` | P1 |

## 4. 工作区与编码

| 功能 | 说明 | 档位 |
|---|---|---|
| 工作区 | 把线程绑定到一个本地目录（`workspaces`，79 条路由） | P1 |
| 文件树、读写文件 | `/files/*` | P1 |
| Git 全套操作 | status、diff、stage、commit、branch、stash、rebase、冲突解决（含 AI 解决冲突）、AI 生成提交信息 | P2（MVP 先只做 diff 展示） |
| Worktree | 自动为每个任务开一个 worktree | P2 |
| GitHub PR | 查看、新建、合并 PR，查看 CI 日志 | P2 |
| 预览服务器 | 识别项目类型，起 dev server，在侧边栏里预览（`preview_servers`） | P2 |
| 内置终端 | node-pty 实现（`/api/terminal`） | P1 |
| 远程主机 | 工作区可以放在 SSH 主机上，能读取 `~/.ssh/config`（`remote_hosts`） | P2（你有 HK、US 两台服务器，以后可能有用） |
| 项目卡片 | AI 为项目生成一张说明卡片 | 不做 |
| 文件改动统计 | 一个线程改了多少行（`thread_diff_stats_cache`） | P2 |

## 5. 多 agent 协作

| 功能 | 说明 | 档位 |
|---|---|---|
| Mission / Sprint / 合约 / 评审 | 一个大目标拆成多个 sprint，每个 sprint 先定验收标准（合约），generator 干活，evaluator 打分（表 `agent_missions`、`mission_sprints`、`sprint_contracts`、`sprint_evaluations`、`agent_runs`、`agent_handoffs`） | P2 |
| 子 agent | 子 agent 的消息和实时状态（`subagent-messages`、`subagents/live`） | P2 |
| Plan Weave | 写成文件的任务图，带依赖和审核关口，重启后进度不丢（`/api/plan`） | P2 |
| Plan 模式 | 先出计划，确认后再执行（`/api/plan-mode`） | P1 |
| 后台派发 | 主对话把大任务派到后台线程去跑（`/api/personal/dispatch`） | P2 |

## 6. 记忆与知识

| 功能 | 说明 | 档位 |
|---|---|---|
| 长期记忆 | 从对话中提取事实，存进 `memories`，用 sqlite-vec 做向量检索，embedding 模型在本地跑 | P1 |
| 记忆“睡眠”整理 | 定期去重、过期清理、合并相似条目、用 LLM 筛选，结果移到 `memory_archive`（`memory_sleep_runs`） | P2 |
| 双链引用 | 文件、线程、消息、主机、技能、模型等任何对象都有 `alma://kind/id` 形式的地址，可以 @ 引用，支持反链、关系图（`/api/refs`，33 条路由） | P2（这个设计很好，值得以后做） |
| 时间线索 | 记录“某天做了什么”的索引，用于生成日报（`time_clues`） | 不做 |
| 人物档案 | 记录联系人信息（`/api/people`） | 不做 |
| Crystal | 把零散素材提炼成可复用的对象 | 不做 |

## 7. 扩展机制

| 功能 | 说明 | 档位 |
|---|---|---|
| 技能（Skills） | 一个目录放一个 `SKILL.md`，兼容 Claude Code 的技能格式。内置 44 个，能扫描 `~/.claude/skills` | P1 |
| MCP 客户端 | 管理 MCP server，支持 OAuth（`mcp_servers`、`mcp_oauth_tokens`），可浏览 resource 和 tool | **MVP**（至少支持 stdio 和 HTTP 两种 MCP） |
| MCP 市场 | `/api/mcp-marketplace` | P2 |
| 插件系统 | 插件可以带权限声明、状态、设置，来源分 local、npm、url、marketplace（`plugins` 三张表） | P2 |
| Hooks | 生命周期钩子（`/api/hooks`） | P2 |
| 提示词库 | 常用提示词（`prompts`） | P1 |
| Prompt Apps | 带占位符的提示词模板，填完就是一个小应用，可以绑快捷键、开独立窗口（`prompt_apps`） | P2 |
| 编程式工具调用 | 让模型写一段 JS/TS 脚本，用 Bun 执行，一次批量调用多个工具（`/api/bun`、`programmatic-tools`） | P2 |
| Secrets | 加密存储的密钥，可以作为环境变量注入给工具（`secrets`） | P1 |

## 8. 自动化

| 功能 | 说明 | 档位 |
|---|---|---|
| 定时任务（cron） | 定时往某个线程发一条提示，有执行历史（`/api/cron`） | P1（你每天 7:30 的 sub2api 汇报就能用它做） |
