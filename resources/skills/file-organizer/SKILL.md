# 工作区文件整理与批量重命名 (`file-organizer`)

面对需要清理下载目录、规范命名或重新归类文件结构的需求时，严格遵守「先盘点方案、再审批执行」两阶段流程。

## 1. 阶段一：只读盘点与制定计划
- 使用 `fs_list`（可开启 `recursive: true`）和 `fs_glob` 扫描工作目录，统计文件类型、数量与大小。
- 如需根据内容判断归属，用 `fs_read`（仅读取前几十行）抽样确认，不盲目猜文件名。
- 输出清晰的 **整理映射表（原路径 → 目标路径）**，并注明：
  - 新建目录清单
  - 重命名规则（如日期前缀 `YYYY-MM-DD_原名`、统一小写连字符等）
  - 潜在冲突处理（重名文件如何加序号后缀，绝不静默覆盖）。

## 2. 阶段二：确认后安全执行
- 涉及写文件或执行命令移动/重命名时，通过需要确认的工具（`shell_exec` 或 `fs_write`）发起操作，确保用户在界面上可见并审批。
- 执行时遵循：
  - 优先移动/重命名而非删除；遇到疑似重复或无用文件，先移入 `_archive/` 或 `_trash_review/` 并列清单，由用户决定是否删除。
  - 若使用 PowerShell 批量移动，确保路径加引号、目标父目录存在且不覆盖已有同名文件（先检查 `Test-Path`）。

## 3. 验收
- 执行完毕后用 `fs_list` 复核目录树，向用户报告成功迁移数量与新目录结构摘要。
