# 网络深度研究流程 (`web-research`)

面对需要最新信息、事实核查、技术选型对比或资料调研的问题时，按以下步骤执行：

## 1. 拆解检索词与多源搜索
- 将复杂问题拆成 2～4 个互补的关键词组合（中英文结合效果更佳）。
- 调用 `web_search` 检索多个角度的资料，避免仅凭单条摘要下结论。

## 2. 深入抓取原文
- 从搜索结果中挑选权威来源（官方文档、一手发布说明、规范标准、源码仓库等），调用 `web_fetch` 获取完整正文内容。
- 注意识别网页时效性（发布日期、适用版本号），剔除过期或明显转载拼凑的内容。

## 3. 交叉验证与冲突标注
- 关键数据、API 行为或结论至少由 2 个独立来源交叉印证。
- 若不同来源存在矛盾，明确列出各方说法、版本差异与可能原因，不强行编造确定结论。

## 4. 输出规范
- 先给出结构化核心结论，再展开关键依据。
- **每条关键事实或数据均附带可点击出处链接**（`[来源标题](URL)`）。
- 若受限于网络、权限或页面截断未能核实某项细节，如实说明检索边界。
